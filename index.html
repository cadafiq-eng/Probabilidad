Bernoulli Be(p) — un solo ensayo con resultado éxito (X=1) o fracaso (X=0). Es el caso especial de Binomial con n=1.
P(X=1) = p · P(X=0) = 1−p · E(X) = p · Var(X) = p(1−p)
Parámetro
La distribución Bernoulli es la base de la Binomial.
Si X₁, X₂, …, Xₙ son ensayos Bernoulli independientes, entonces
Y = X₁+X₂+…+Xₙ ~ Binomial(n, p)

Hipergeométrica H(N, K, n) — muestreo sin reemplazo. N=población total, K=éxitos en población, n=tamaño de muestra.
E(X) = nK/N · Var(X) = nK(N−K)(N−n)/[N²(N−1)]

Geométrica Geo(p) — número de ensayos hasta el primer éxito. Caso especial de Binomial Negativa con r=1.
P(X=k) = (1−p)^(k−1)·p · E(X) = 1/p · Var(X) = (1−p)/p²
Propiedad de falta de memoria: P(X > m+n | X > m) = P(X > n)

Binomial Negativa BN(r, p) — número de ensayos necesarios para obtener el r-ésimo éxito. Generaliza la Geométrica (r=1).

E(X) = r/p · Var(X) = r(1−p)/p²

Tablas Estadísticas

P(X ≤ k) calculada con 4 decimales — compara con las tablas de tu libro de texto

Tabla Binomial — P(X ≤ k; n, p)
Selecciona n para generar la tabla con los valores de p estándar. Las celdas resaltadas en dorado corresponden a la moda.
p = 0.05, 0.10, 0.15, 0.20, 0.25, 0.30, 0.40, 0.50, 0.60, 0.70, 0.75, 0.80, 0.90, 0.95
Tabla Poisson — P(X ≤ k; λ)
Valores acumulados para los λ más comunes en aplicaciones de ingeniería y ciencias.
Tabla Normal Estándar — Φ(z) = P(Z ≤ z)
Para z negativa: P(Z ≤ −z) = 1 − Φ(z). La tabla cubre z = 0.00 a 3.99.
Tabla t-Student — valores críticos t_{α, ν}
Cola derecha: P(t > t_{α,ν}) = α. Para bilateral con nivel 95%: usar columna α = 0.025.
Tabla Chi-cuadrada — χ²_{p, ν}
P(χ² ≤ χ²_{p,ν}) = p. Por ejemplo: χ²_{0.95, 10} = 18.307 → P(χ² ≤ 18.307) = 0.95.
Tabla F de Fisher — F_{α, ν₁, ν₂} (cola derecha)
P(F > F_{α,ν₁,ν₂}) = α. Filas = ν₂ (denominador), columnas = ν₁ (numerador).
ν₁ = gl numerador (columnas) · ν₂ = gl denominador (filas)
